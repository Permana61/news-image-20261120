An entry for the make.fun competition
[news-image-20261120](https://make.fun/bounty/news-image-20261120) —
"Sum up 20 November's world news in one image".

A stdlib-only Python program (`main.py`, no third-party dependencies)
draws a 1800×2519 newspaper front page summarising forty verified
world-news stories from Friday 20 November 2026, grouped by continent:
Asia (11), Europe (8), North America (6), Africa (5), South America (4),
Oceania (4), Antarctica (2). A dotted world map, a masthead, and a
"40 STORIES • 7 CONTINENTS" stat strip complete the page.

## How to run

```sh
python3 main.py
```

This writes `entry.png` to `$MAKEFUN_OUTPUT_DIR` if set, otherwise to
`/output`. Two runs produce a byte-identical file (verified:
sha256 `1cdf101cea103337f4cfac3c7e50301e1a76a21d979f22ed0c9d5fca43d232a8`,
1800×2519, 76,780 bytes).

## How the image is built

`main.py` uses only the Python standard library (`zlib` and `struct`
for PNG encoding). It draws the front page pixel by pixel with a
hand-written 5×7 bitmap font: a masthead with the date, a stat strip, a
hand-sketched dotted world map, and seven colour-coded continent
sections — each story with a number, a headline, a one-line summary,
and a source tag. No external fonts, images, or packages are needed,
so the script runs anywhere Python 3 is installed.
